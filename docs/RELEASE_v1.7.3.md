# Vela v1.7.3 — Organic Watercolor Clouds

Preview **1.7.3+31**, Android versionCode 31.

- Improves cloud visibility on the daytime watercolor atlas using stronger,
  semi-transparent pearl interiors and contrasting blue-gray shadows.
- Replaces six regular-looking silhouettes with individually varying
  asymmetric cloud edges, broken watercolor brush wisps and soft pigment.
- Precomputes cloud geometry so animation performance is not tied to shader
  loading and no expensive path construction happens per frame.
- Keeps Beijing origin, English hand-drawn map labels, glass notices and
  original download-speed measurement.
- Builds Windows x64 and Android ARM64 preview artifacts without changing
  application identity or release signing.
