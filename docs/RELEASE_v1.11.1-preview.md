# Vela 1.11.1+64 稳定性维护测试版

基于 v1.11.0 正式版开发；本次为独立 GitHub Actions 产物，并非新的正式 Release。

- 继续每两分钟检测一次真实出口 IP，首次连接保留原有失败重试。
- 已验证 IP 最多保持 6 分钟；持续检测失败会使结果过期，不再无限显示旧地址。
- 保存 Go/Mihomo 检测返回的实际出口链、core-epoch 和 picks-version；全局模式不将 DIRECT 链误判为代理出口，直连模式校验 DIRECT；规则模式允许按路由实际选择出口。
- 设置页新增本地“网络诊断”：原生链路、最近有效时间、失败原因、代理模式、手动重试；不会保存或上传 IP、节点链路、检测接口和订阅 URL，DNS 不声称已独立检测。
- 保留原油画界面和国旗、小船、地图动画、Android 真实 VPN、Windows 系统代理；两端共享 FlClash Go 内核。
- Windows x64 和 Android ARM64 重新构建并签名，Android versionCode 64，同证书支持覆盖版本 63。

上线前仍须通过双端 CI、真实连接/切节点及真实网络环境的设备验证。
