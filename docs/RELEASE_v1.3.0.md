# Vela-SHUO v1.3.0 — 稳定版

定版日期：2026-10-14

## 定版范围

Vela v1.3.0 以用户验收认可的 v1.2.4 为**唯一功能基线**，原始提交：
`40a55511d832fe7fe2dcf427f10a221de8b671e7`（`feature/v1.2.4-sail-glass-50`）。

本次升版仅调整 Flutter 版本号、程序版本文案、Windows 托盘提示、构建工作流和安装包名称、发行说明；
不重新设计界面，不修改订阅、代理、VPN 或内核业务逻辑。

- Flutter 版本：`1.3.0+8`
- Windows 包：`Vela-v1.3.0-Windows-x64.zip`
- Android 包：`Vela-v1.3.0-Android-arm64.apk`
- 维护分支：`release/v1.3.0`

## 正式保留功能

1. **统一蓝金帆船标识**：应用主 Logo、首页/导航、桌面程序图标、系统托盘、Android 启动图标和地球航线上的移动帆船采用相同品牌语言。
2. **昼夜地球**：浅色主题为自然色白天地球，深色主题为卫星城市灯光夜景，带平滑过渡，保留清晰的地表纹理、航线与转动动画。
3. **50% 透明毛玻璃**：前景主要功能卡片、代理/配置模块、侧栏与底部导航统一为约 50% 不透明度，局部模糊不影响地球背景。
4. **航线模式**：规则 / 全局 / 直连，通过底层网络服务真实切换，支持模式保存与订阅重新导入后的同步。
5. **订阅管理**：多机场订阅存储、导入/更新、切换及恢复，当前航线显示机场名称。
6. **Windows 托盘与退出**：点击关闭按钮隐藏到托盘；最小化与安全退出保留既有行为。
7. **轻量动画**：标志进入、界面切换、卡片反馈、地球昼夜过渡和航线航行。

## 验证与限制

用户确认的 v1.2.4 基线 CI 全部成功，包括 Flutter 静态分析、回归测试、Windows x64 和 Android ARM64 构建：
https://github.com/shuowang0217/Vela-SHUO/actions/runs/38529442266

v1.3.0 **重新构建的 CI 必须独立成功**，才表示正式版安装包已经生成并验证了打包完整性。CI 通过不代表完成真实设备的全部 VPN/代理功能验收。

## 定版规则

`release/v1.3.0` 作为稳定基准保留；新功能与下一版本修改应从单独分支进行，不覆盖此版。
