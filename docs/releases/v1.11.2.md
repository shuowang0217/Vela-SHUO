# Vela v1.11.2 — Stable

Release date: 2026-11-05

Vela 1.11.2 is the stable Windows x64 and Android ARM64 release, promoted from the validated v1.11.2-beta.3 network-resilience preview.

## Highlights

- Real HTTPS streaming download measurements through each selected Mihomo/FlClash proxy; rank by measured MB/s, not latency.
- Short first-pass samples and longer verification for the fastest five, with up to three additional replacement candidates when ranks change.
- Preserve real bytes received before a bounded probe timeout, without treating latency failures as download failures.
- Retry top-ranked nodes using the CDN that provided their first successful measurement.
- Show per-node quick/verified results, whole-scan elapsed time, and distinct queued/in-progress/success/failure states.
- Keep native download scans serialized to avoid connection contention and preserve core reliability.
- Maintain the original Vela UI and FlClash-Custom/Mihomo networking stack.

## Downloads

- **Windows x64**: `Vela-v1.11.2-Windows-x64.zip` — extract the complete archive and launch `Vela.exe`.
- **Android ARM64**: `Vela-v1.11.2-Android-arm64.apk` — built with the established Android release signing certificate.

Both files are supplied with SHA-256 checksum text files. Check the platform and archive checksum before installation. Windows executable signing depends on the publisher certificate supplied to the build environment.

Build provenance: signed, versioned binaries are built in GitHub Actions from the release branch, with Flutter static analysis, UI/unit tests, the pinned native FlClash Go backend, and platform-specific validation.

Source version: `1.11.2+68`.
