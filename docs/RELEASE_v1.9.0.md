# Vela 1.9.0 正式版

**定版版本：1.9.0+53**。Android `versionCode=53`，应用包名 `com.shuowang.vela`，沿用固定永久正式签名，支持同签名旧版本覆盖更新。

Vela 1.9.0 基于用户对 Windows 和 Android 最新测试版的实机验收定版。本次发布专注稳定性、跨平台界面一致性和机场管理，不更换网络内核。

## 主要变化

1. **机场配置卡片等高。** 当前使用的机场始终排第一，选中状态轻微强调；Windows 维持原有双列宽度，同排两张卡片按内容等高，避免自动更新说明多占一行导致高度错位；Android 保留单列统一基础高度。
2. **Windows 海域装饰航线修复。** Windows 网格生成固定 LF，解析兼容 CRLF/LF；保留航行小船和流光效果。
3. **Android 油画实时通知。** 复用实际带海鸥、帆船、海面的海景素材，完整显示上下行速度；系统通知外框仍由 Android 或厂商系统决定。
4. **代理模式设置。** Android 对规则、全局、直连模式进行原生保存和读取校验，避免仅运行时切换生效却丢失本机设置；规则设置弹窗不再无端压暗地图。
5. **机场自动更新。** 支持最短 15 分钟的订阅更新检查、失败冷却重试和恢复前台复查。**仅保证 Vela 进程运行期间的调度；完全退出后不能保证后台更新。**
6. **延迟测速显示。** 用户可见状态使用 Vela 名称，测速仍委托经过验证的原生 FlClash/Mihomo 内核。

保留 1.8.0 的航海油画地图、多主题、节点切换、机场流量显示、代理/VPN 和双向实时网速通知功能。地图航线仅为装饰，不用于实际航海导航。

## 安装

- **Android ARM64：** `Vela-v1.9.0-Android-arm64.apk`，正式签名，包名 `com.shuowang.vela`，versionCode 53，可覆盖相同签名的旧版。
- **Windows x64：** `Vela-v1.9.0-Windows-x64.zip`，安全退出旧版后完整解压，运行 `Vela.exe`。

## 发布校验

正式 Release 仅在 Flutter 静态分析、UI/单元回归测试、Windows 原生核心与程序编译、Android 原生 VPN 编译、APK 签名和证书验证、包名/版本号检查、SHA-256 校验及安装包 ZIP 结构验证全部通过后由 CI 自动创建。

发布分支：`release/v1.9.0`，对应版本标签 `v1.9.0`。此前 `v1.8.0` 等历史正式版本保持不变。
