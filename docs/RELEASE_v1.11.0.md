# Vela v1.11.0 正式版 · 出口 IP 检测与油画国旗

**正式版本：1.11.0（构建号 63）**，从已通过双端构建及 Flutter 全套回归测试的 `1.10.1-beta.4+62` 定版，保留 v1.10.0 中的全部航海风格 UI、安卓「航行开关」快捷入口、机场管理与 FlClash/Mihomo 网络功能。

## 本次新增

- **真实出口 IP 与地区**：在首页右上角原有的连接状态模块内增加一行简洁显示：检测成功时为**油画国旗 + 出口公网 IP**，失败为 `timeout`；不新增独立卡片。
- **FlClash 原生检测**：Windows x64、Android ARM64 都通过固定版本的 FlClash Go 内核 `outboundIp` RPC 和 Mihomo 实际路由发起检测，使用 8 个 HTTPS 数据源、最多 3 路错峰并发。不根据节点名称猜测 IP 或国家。
- **连接自动检测与状态稳定性**：VPN/系统代理建立后等待短暂原生路由就绪再检测；首次失败以有限的递增间隔自动重试；节点或路由模式变化清除旧结果；切换窗口不会反复检测；同一线路自动刷新期间保留上一次有效结果。
- **保留两分钟周期**：连接期间每两分钟复检一次出口 IP；断开连接后停止检测并显示 `timeout`。
- **油画国旗**：国家/地区代码映射到应用本地旗帜矢量图形，绘制油彩短笔触、暖色画布纹理与轻浮雕边框，避免 Windows 国旗 emoji 退化成国家代码。支持日本、美国、新加坡、香港、台湾、韩国、英国、德国等常见地区，较少见的地区使用相同风格的代码徽章兜底。无需额外联网获取国旗。

**注意**：`timeout` 意味着出口 IP 查询未成功，不是所有互联网网站都不可访问的充分证据。地图上的航线、城市名称独立于 IP 查询。

## 安装与升级

- **Android ARM64**：`Vela-v1.11.0-Android-arm64.apk`；应用 ID 仍为 `com.shuowang.vela`，`versionName=1.11.0`、`versionCode=63`。使用之前正式版及测试版相同的永久签名证书，可在设备允许时覆盖安装 `v1.10.0+58`、`1.10.1-beta.4+62` 等较低构建号，通常保留现有机场和偏好。第一次使用 VPN 仍需要 Android 授权。
- **Windows x64**：`Vela-v1.11.0-Windows-x64.zip`，内含 `Vela.exe`、FlClash Go 与 Mihomo 固定版本原生核心及必需资源。退出旧版后完整解压替换目录；不要只替换 EXE。
- 两端内核来源与 v1.10.0 保持一致；Windows 使用系统代理、Android 使用真实 `VpnService` TUN，底层入网方式不同。
- 应用内「检查更新」读取 GitHub 最新正式 Release；不会静默下载安装。

## 签名、构建、完整性

仅 `release/v1.11.0` 分支可在 Flutter 分析/回归测试、Windows x64 原生编译、Go RPC 测试、Android ARM64 JNI/VPN 编译、Android 长期签名证书指纹校验、版本号/包名验证以及 SHA-256 和 ZIP/APK 结构校验**全部成功**之后，由 CI 自动创建 `v1.11.0` 正式 GitHub Release，并上传双端安装包及对应校验文件。旧版 Release 与标签不会被覆盖。

此版继承 `v1.10.0` 及 `1.10.1-beta.4+62` 已经通过的自动化验证结果；实际设备的网络路由、国旗视觉效果仍由用户安装后进行验收。
