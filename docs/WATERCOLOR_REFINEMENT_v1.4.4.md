# Vela v1.4.4 · 双端水彩世界地图日夜精修（预览版）

基线：v1.4.3 `feature/v1.4.3-android-notification-glass-map-fix`；**不覆盖 v1.4.0 正式版**。

## 共用的日景/夜景

- 日景：保留用户原始 1774×887 水彩地图的所有海岸线、山脉、地理位置、纸张颗粒和水彩笔触；适度提升对比、色彩层次和细节，避免滤镜过度锐化。
- 夜景：在原有夜景画作上加入偏深蓝的蓝调时刻分级，让海面更沉静、陆地轮廓保持清晰。不是单纯把白天画面调暗，也不重新描绘海岸线。
- 城市灯光：沿用仓库原有地理配准的 `assets/earth/earth_night_lights.png`，屏蔽微弱噪点，并分别加入金色中心、局部柔光与更弱的远光晕；灯光图层在夜景调色**之后**合成，避免城市灯光被重新染成灰白色。
- 缝合：保留跨 ±180° 地图拼接边缘修复；两边首末列字节一致、可无缝平铺。
- 依赖：只使用已有 Pillow 构建工具。图片在 CI 每个 job 工作区由 `scripts/prepare_watercolor_atlas.py` 生成；源图不直接改写仓库，运行时无网络下载、不依赖叠加额外 Widget。
- Windows 和 Android：保持 `world_atlas.dart` 的相同贴图、日夜切换动效、城市和节点经纬度、航线、缩放/羽化处理；不更改 VPN/代理核心。

## 测试/验证

- `flutter test` 应通过水彩地图共用资产回归测试。
- CI 运行 Pillow 图像预处理、静态检查、Flutter 测试，并分别打包 Windows x64 与 Android ARM64。
- 预处理会检查原图 2:1 几何、地图无缝首末列与城市灯光确实改变夜景输出。
- CI 成功只能说明构建与自动测试通过；Windows/Android 真机视觉和通知兼容性仍需人工验收。

构建入口：GitHub Actions 当前开发分支 `feature/v1.4.4-watercolor-day-night-polish`。正式稳定版 `v1.4.0` 保持冻结。
