# Vela v1.7.4 — Dense Organic Hand-painted Clouds

Preview version **1.7.4+32** (Android build 32).

- Daytime cloud bodies use dense pearl-colored pigment and blue-gray
  under-shadows to remain clearly visible on the watercolor atlas.
- Six independent natural cloud contours have different vertical profiles,
  jagged peaks, broken feathering and uneven watercolored edges.
- Unique silhouettes and wisps are recorded into cached Canvas pictures;
  each animation frame only translates them over the unchanged world map.
- Retains Beijing as origin, English hand-lettered map names, glass toasts,
  original download-speed measurement, and pinned native Mihomo core.
- Windows x64 and Android ARM64 preview artifacts use the existing app
  identity and Android signing identity.
