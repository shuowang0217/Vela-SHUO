# Vela v1.4.3 · Android VPN 实时速度通知

基线：v1.4.2 双端功能修复成功构建分支，不覆盖正式 v1.4.0。

- Android 原生 `VpnService` 的前台常驻通知在验证 HTTPS 成功后，每约 2 秒读取一次 FlClash/Mihomo JNI 累计流量计数，按系统单调时钟计算**字节/秒**的差值。
- 通知内容：`↑ 风速 0 B/s · ↓ 航速 2.40 MB/s`，支持 B/s、KB/s、MB/s、GB/s 自动换算；流量未稳定前显示采集中或暂无数据，不捏造测速。
- 不需要 Flutter 页面常驻：切到其他 App 仍然显示通知，停止 VPN、系统撤销权限或 VPN 验证失败会取消采样器及通知。重复更新静默，降低打扰。
- Android 13+ 用户需要同意系统通知权限。拒绝后仍可使用 VPN，但系统可能不在普通通知栏显示前台服务通知。
- 通知帆船图标为 Android 状态栏单色矢量图标；点击通知返回应用，通知操作可断开 VPN。
- Windows 源码和代理逻辑保持原样，版本号同步升至 v1.4.3，CI 同时构建两端用于回归验证。
- 原生 Kotlin 编译和静态接口回归测试成功后，再要求 Android 真机验证不同通知权限状态、息屏、后台切换及速度准确性；CI 不能证明厂商系统后台通知策略。
