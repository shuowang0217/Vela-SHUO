# Vela-SHUO Windows 可选主题（2026-10-10）

## 来源与顺序

遵照 2026-10-10 确认的截图，选择 [Color Hunt — Popular / All time](https://colorhunt.co/palettes/popular) 页面可见的前八套四段配色，保持截图顺序。实际站点热门排行会变化，因此 **本版固定色值与排序**，避免将来更新造成用户主题无意变化。

## 使用方式与技术实现

- 「设置 → 主题配色」以 4 格（窄窗为 2 格）排列八张可点击色卡，每张色卡展示原始四段颜色。
- 单击主题立刻重新渲染导航、全局背景、卡片、按钮、标题、统计卡与地球航线/帆船强调色；更改不要求重启应用。
- 选择浅色套系自动切换浅色模式，深色套系自动切换深色模式。用户随后仍可手动更改「深色 / 浅色 / 跟随系统」。
- 为保证文字/按钮对比度，界面实际背景、边线和字体是由四段原色计算出的适配色；色卡 **始终显示原始 HEX**，不做改变。
- 默认是第 8 套「深海航迹」；旧安装升级时若之前没有存储 palette id 会使用此默认值。
- 主题标识使用单独的 `vela.shuo.palette.v1` key 存于本地偏好，失败时回退默认，非法值只清除此键，不触碰节点或其他设置。
- 地球原始卫星地形与云层、帆船航线动画规则不变；原始帆船产品 Logo 也保持不变。

## 验收

- 各色卡与屏幕一一对应，选择后背景、卡片和强调色确实改变。
- 关机/重开仍记住上次选择；无效存储值回退第八套。
- 8 套主题各自在窗口缩放下文字仍可读；不将浅色文字绘制到浅色背景。
- 不影响 v0.1-C 可靠性、日志隐私、UI 演示状态与 Windows EXE 打包。
- Windows 正式版发布前仍需进行实际屏幕及 DPI/不同窗口高度验收。
