## 近期实施顺序

1. 在已冻结首页 UI 的基础上完善回归测试：三种 DPI、窗口缩放、连接完成前后船只运动、断开/重连中断、品牌文案锁定。
2. **0.1-C 收尾：**验证本地诊断、非法偏好数据、存储故障和无响应超时；完成 Windows 杀进程/断电后恢复、系统睡眠/唤醒的实机检查。当前代码不涉及代理进程。详细见 [RELIABILITY_0_1_C.md](RELIABILITY_0_1_C.md)。
3. **0.2 分阶段：**0.2-a 已实现外部 sing-box 进程与本地端口监听流程（详见 [CORE_0_2_ALPHA.md](CORE_0_2_ALPHA.md)）；0.2-b1 已提供 HTTPS 订阅导入、手选节点、生成内核配置和外网 HTTPS 检测（详见 [SUBSCRIPTION_0_2_B.md](SUBSCRIPTION_0_2_B.md)）；继续推进其余订阅格式、节点管理、用户授权后系统代理的完整备份与恢复，以及安全错误分类。
4. **0.3 智能切换：**测速/稳定性得分、触发阈值、滞后、退避、冷却、防频繁切换；异常恢复测试。
5. 确认真实流量连接、Windows 便携/安装、异常重启及系统清理行为后再作为正式版发布，之后恢复 Android。

## 安全及产品底线

- 演示版只能显示模拟数据；没有真实连接时不应声称已联网或显示真实性能测试值。
- 不依赖 FlClash-Custom 源码，也不覆盖旧软件安装身份、配置与网络设置。
- 系统代理/VPN 的改变必须可识别、可退出、可恢复，敏感信息不进入本地日志。
- GitHub Actions 暂时只构建 Windows x64，Android 不随每次提交自动构建。
