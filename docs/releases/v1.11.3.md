# Vela v1.11.3 — 正式版 / Stable

发布日期：2026-11-06  
支持平台：Windows x64、Android ARM64  
应用版本：`1.11.3+69`

本版将已经双端实际验证的 AutoSmart 智能优选功能定版发布。保留原有 Vela 油画航海界面及 FlClash-Custom / Mihomo 原生网络内核。

## 主要更新

- **连接状态下自动测速**：启用智能优选后，程序运行期间自动按设定周期执行真实 HTTPS 节点下载测速。保持 Windows 系统代理或 Android VPN 已连接，不再因为在线状态跳过定时检查。
- **在线智能切换**：满足用户配置的实际下载速度提升阈值和冷却时间后，调用 Windows/Android 原生 Mihomo 选路接口，确认成功才更新所选节点；失败沿用既有恢复机制。不会自动打开网络代理或 VPN。
- **自定义检测周期**：1、3、5、10、15、30、60 分钟，默认 10 分钟。
- **自定义速度提升门槛**：提供 0%～100% 多档选项，默认 20%。
- **自定义切换冷却**：可设为不限制，或 1、3、5、10、15、30 分钟，默认 3 分钟。
- **保存设置**：智能优选开关、AI 国家限制及三个切换参数持久化保存，重启应用后恢复。
- **优选测量一致性**：维持串行原生下载测速与最快候选复测；独立下载测速结束后也能参与自动优选；真实下载测量成功但延迟探测失败的节点仍可作为速度候选。

## 下载与安装

- **Windows x64**：`Vela-v1.11.3-Windows-x64.zip`。退出旧版后完整解压，运行 `Vela.exe`，不要只替换 EXE。
- **Android ARM64**：`Vela-v1.11.3-Android-arm64.apk`。沿用 `com.shuowang.vela` 包名和永久正式签名，`versionCode=69`；可从低于 69 的同签名版本直接覆盖安装并保留现有数据。

Windows 与 Android 均提供独立的 `SHA256-Windows.txt` / `SHA256-Android.txt` 完整性校验。Windows EXE 的可信发布者签名仍取决于构建环境是否配置发行者证书。

## 运行说明

- 自动检测仅在应用运行、智能优选启用且内核可用时工作；关闭程序后不进行后台测速。
- 人工选择节点时会暂停自动切换，需要从智能优选面板恢复自动优选。
- 真实 HTTPS 测速可能消耗下载流量；短时测速属于采样值，不能代表持续独占线路带宽。
- AI 国家筛选仅对符合国家名称的节点参与自动优选；自动换节点不改变 VPN/系统代理开关状态。

## 发布验证

GitHub Actions 使用固定 FlClash-Custom / Mihomo 源码版本，先执行 Flutter 静态检查、单元与界面回归测试，再分别构建 Windows x64 与 Android ARM64；发布作业在两端产物、Android 签名、版本号及 SHA-256 校验全部通过后创建稳定版 Release，保留历史版本。

本次基线为经实际双端测试的 AutoSmart 修复代码；正式包仅进行版本递增、发布说明和打包流程调整。
