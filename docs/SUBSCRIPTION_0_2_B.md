# Windows v0.2-b · 订阅导入与节点连接（Beta）

本阶段已将用户自行提供的 **HTTPS 订阅链接** 的导入、节点选择与本地 sing-box 运行流程接入 Windows 设置页。与先前首页的视觉演示不同，这是真实的节点配置和进程启动基础；但本阶段仍不自动修改 Windows 系统代理，尚未进行用户 Windows 实机连接验收。

## 使用

1. 解压完整 Windows 便携 ZIP（内置上游官方 sing-box 1.14.3）。进入「设置 → 订阅导入与节点管理」。
2. 将自己的 HTTPS 订阅链接粘贴到隐藏输入框，点击「导入订阅」。输入框导入后清空，不在 ChatGPT 中发送链接，也不保存到普通设置或诊断日志。
3. 列表会显示 **解析成功 / 跳过节点** 数目，点击一个目标节点，会生成仅含所选节点的 sing-box JSON 本地配置。
4. 下方「本地代理内核」模块点击「启动本地代理」；仅检测本机 127.0.0.1:20808 端口是否被监听。
5. **如需检测实际线路**，在本地代理启动后点击「验证真实外网连接」；使用当前 HTTP 代理访问 `https://cp.cloudflare.com/generate_204`，仅在收到合法 HTTPS 证书和预期 204 响应时报告当前检测成功。
6. 可手动将其他软件的 HTTP/SOCKS5 代理设为 `127.0.0.1:20808`；当前版本不会自动代理系统流量。
7. 下次重启需重新输入订阅：本阶段不保存订阅链接、访问 Token 或远程节点列表。

## 兼容范围（保守导入）

支持尝试解析：
- Clash/Mihomo **YAML**：常见 SS、VMess、VLESS、Trojan、Hysteria2；转换 TCP、WebSocket、gRPC 以及常用 TLS、Reality 信息。
- sing-box **JSON**：独立、支持的真实远端 outbound。
- 跳过未知协议、前置插件、依赖其他出站 detour 的节点、主动关闭 TLS 证书校验的节点、不支持的网络传输方式。
- 自动构建本地 `mixed` 入站及指定的单节点 outbound，强制 `127.0.0.1:20808`，不信任原订阅可能包含的系统路由、inbound、TUN 或 DNS 重写指令。
- 节点参数在 sing-box 官方 `check` 运行时还会再次校验。**配置结构成功解析不保证所有节点兼容**。

不支持：通用 base64/V2Ray 分享链接订阅、节点订阅自动定期更新、Clash 全规则语义转换、复杂链式代理、基于地理位置的自动节点识别和自动测速。部分 Reality/传输组合仍需实际 sing-box 检查与真实线路测试，不能声称全部协议组合完美兼容。

## 安全与限制

- HTTPS 订阅不允许 URL 带用户信息、IPv4/IPv6 IP 字面量、localhost 或 .local 主机；对 DNS 初步排除私网/保留地址，禁止 30x 跳转。**DNS 检查仍非严格连接级 DNS pinning**，后续要进一步处理 DNS rebinding、压缩炸弹和代理环境。
- 订阅响应大小限制 2 MiB，限制最多 500 个节点；外部订阅 URL、原文和私密服务器参数不写入诊断记录，也不会复制到 GitHub。
- 含有节点凭据的**当前已选择配置**写入 `%LOCALAPPDATA%\Vela-SHUO\Profiles\subscription-active.json`，由当前 Windows 用户访问；程序下次启动会尝试删除旧文件。请不要将这个目录打包分享给其他人。
- 远端验证使用 Cloudflare 固定 HTTPS 地址，只能证明当前测试请求通过本地代理成功，并不能代表所有站点可达或下载测速结果。
- 不主动更改注册表或系统代理；不触碰旧项目配置，不请求 TUN/管理员权限。进程异常退出会清除本地监听状态。
- 真实功能与首页地球动画仍分离：**目前首页连接按钮仍是明确标注的演示**，没有把演示测速/帆船动画伪装成真实线路状态。
