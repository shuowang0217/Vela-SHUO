# Vela 1.8.0 正式版

Vela 1.8.0 基于已完成用户实机测试的 **1.8.17+51 油画版** 定版。
本次不引入额外功能，以稳定的双端构建、持续可用的 VPN/代理核心和地图体验为正式版基线。

**正式版本：1.8.0+52**。Android versionCode 为 **52**，高于此前 v1.8.17 测试包的 51；包名和原有正式签名不变，支持覆盖安装。

## 正式版主要功能

- 保留沉浸式航海油画地图，Windows 和 Android 统一明暗油画、循环地图背景、半透明主题卡片。
- 连接节点后，镜头平滑聚焦到对应城市；油画模式的海上装饰航线依据画面海域寻路，船只和流光同步。
- 保留 v1.6 风格主页布局、机场已用流量 / 总流量进度条、所有主题下的高辨识度浮动通知。
- 手机配色能够保存并在重新启动后恢复；沿用已验证的 Android 原生持久化实现。
- 保留 FlClash / Mihomo 网络核心、节点切换、机场订阅、系统代理与 VPN 功能。

> 地图航线仅用于视觉效果，并非真实航海导航数据。

## 安装

- **Android ARM64**：`Vela-v1.8.0-Android-arm64.apk`，使用原有 Vela 正式签名，可在相同签名的测试版上覆盖升级。
- **Windows x64**：`Vela-v1.8.0-Windows-x64.zip`，完整退出旧版后解压全部文件，运行 `Vela.exe`。

由于正式版显示版本号从测试版 1.8.17 回归为 1.8.0，**已安装测试版的应用内语义版本更新检查可能不会主动提示本次正式版**，请通过此 Release 页面手动升级。后续正式版本按 1.8.x / 1.9.x 正常递增。

## 发布验证

仅当 Flutter 分析及全部 UI/单元测试、Windows 构建、Android 签名及包名版本验证、两个压缩包完整性检查和 SHA-256 校验全部通过后，GitHub Actions 才会发布本条正式 Release。

正式发布时保留历史 v1.7.0、v1.6.0 等 Release，不覆盖既有安装包。
