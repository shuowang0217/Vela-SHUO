# Windows v0.2-a · 真实本地代理内核（Alpha）

## 已实现

独立于首页演示动画的本地 sing-box 运行控制：在 **设置 → 本地代理内核** 使用随 Windows 便携包附带的官方 `sing-box.exe`，并在首次启动时自动创建纯本地 `direct` 测试配置。无需先自行下载二进制或准备本地代理。用户也可以手动选择自己的 sing-box 和 JSON 配置，选择后先解析配置基本结构；点击启动依次执行：

1. 重新读取配置，检测导入后端口是否变化。
2. 调用选定 sing-box 的 `check -c <file>` 执行官方配置检查（最长约 12 秒）。
3. 确认本机端口尚未占用，启动 `run -c <file>` 子进程。
4. 检查 `127.0.0.1:<port>` 是否在约 8 秒内开始 TCP 监听；如果失败，则尝试终止该子进程。
5. 只显示 **「本地端口已监听（非外网连通验证）」**，不会把此检查当作远程线路、DNS、出口 IP 或下载速度已成功的证明。
6. 选择停止时终止 Vela-SHUO 启动的子进程；子进程意外退出时立即清除“本地已监听”状态。

这是真实的本地代理进程启动能力，**不是仅按钮模拟**；但内核文件不随测试版分发，内核来自 sing-box 官方稳定版发行资产 `v1.14.3`，CI 必须验证固定 SHA-256，并随包提供 GPLv3 文本、上游署名和对应源码地址。详见 [第三方公告](../third_party/sing-box/NOTICE.md)。相关命令参考 [sing-box 官方文档](https://sing-box.sagernet.org/configuration/)。

## 为安全限定的支持范围

- 目前仅支持 **恰好一个** `type: "mixed"` 或 `type: "http"` 入站，要求 `listen: "127.0.0.1"` 和 `listen_port` 在 1024–65535；必须含至少一个 `outbounds`，不允许公开监听 `0.0.0.0`、局域网 IP 或其他公网地址，不允许 TUN/透明代理。
- JSON 限制 2 MiB；输入文件只在本机原路径读取。**不存入偏好设置、不复制到云端、不打印配置内容或子进程 stdout/stderr**（这些可能含密码、订阅密钥或节点信息）。
- 仅检查入站基本安全形状，更多协议兼容性由 sing-box 本身的 `check` 命令判断；不宣称 Vela-SHUO 已完成完整的 JSON Schema 或订阅格式验证。
- **不更改 Windows 系统代理、不接管其他应用网络流量、不申请管理员权限**。用户可在支持手动代理的客户端软件中自行将 HTTP 或 SOCKS5 代理设为界面显示的 `127.0.0.1:<port>` 进行测试。
- 出站是否可用由用户配置决定。使用 `direct` 出站只代表直连，不能说明跨境代理线路已通。自动测速、订阅 URL 下载、节点自动选择、系统代理/TUN 模式仍待开发。

## 当前限制与风险

- 应用正常关闭/切换页面时会尝试清理受控子进程；若进程被操作系统强制终止，Windows 未必自动清理子进程。由于本阶段不修改系统代理，至少不会遗留由本客户端修改的系统代理配置。
- **本地端口开放不能证明是受控进程所监听，更不能证明远程网络可达**，真实线路检验尚需独立端到端代理请求验证。
- 导入的 JSON 是第三方配置文件，可能在支持的 sing-box 功能中调用外部资源或暴露其他服务。请仅导入可信配置；此 Alpha 对基本入站约束之外的全部安全选项尚未完成严格白名单审计。
- 内核二进制由 Windows CI 从固定的 sing-box 官方稳定版发行包下载并校验 SHA-256，分发时随便携 ZIP 附带；首次启动不联网下载，也不自动执行。用户主动点击「启动本地代理」才执行。用户仍可在高级模式下自行选择外部可信内核。
- 当前不持久化第三方配置路径：关闭 Vela-SHUO 后需重新选择自定义 JSON（内置无密码的直连测试配置会自动再创建），并且**绝不自动启动敏感网络服务**。

## 最小测试配置示意（仅展示形状，不提供网络服务）

```json
{
  "inbounds": [{
    "type": "mixed",
    "listen": "127.0.0.1",
    "listen_port": 20808
  }],
  "outbounds": [{"type": "direct", "tag": "direct"}]
}
```

此示意是本地 HTTP/SOCKS 混合代理、出口 **直连**，不含海外服务器，也不会提供跨境连接。此版内置自动创建的配置正是此种测试性质的配置。实际远程代理仍需用户自己的合法节点或订阅，并通过后续配置/订阅管理进行连接。

首页已确认的地球、返航、字体与八套主题保持不变。Android 开发仍冻结至 Windows 正式版之后。
